# Evidencias Visuales - VetCT

## Instrucciones para Capturas de Pantalla

Para añadir las evidencias visuales al documento del TFG, sigue estos pasos:

### 1. Capturar las Pantallas Principales

#### Panel de Recepción
- URL: `http://127.0.0.1:8000/notificaciones/recepcion/`
- Guardar como: `panel_recepcion.png`
- Incluir: Notificaciones pendientes y botones de acción

#### Panel Veterinario  
- URL: `http://127.0.0.1:8000/notificaciones/veterinario/`
- Guardar como: `panel_veterinario.png`
- Incluir: Pestañas y tablas de citas

#### Detalles de Cita
- URL: `http://127.0.0.1:8000/notificaciones/ver/consulta/1/`
- Guardar como: `ver_cita.png`
- Incluir: Formulario completo con datos del paciente

#### Panel de Usuario
- URL: `http://127.0.0.1:8000/users/mis-citas/`
- Guardar como: `panel_usuario.png`
- Incluir: Lista de citas del usuario

### 2. Capturar Diseño Responsivo

- Usar herramientas de desarrollador del navegador
- Probar diferentes tamaños: móvil (375px), tablet (768px), escritorio (1200px)
- Guardar como: `responsive_design.png`

### 3. Herramientas Recomendadas

- Windows: Snipping Tool o Win + Shift + S
- Mac: Cmd + Shift + 4
- Navegador: Herramientas de desarrollador (F12)

### 4. Formato de Imágenes

- Formato: PNG
- Resolución mínima: 1920x1080
- Calidad: Alta
- Tamaño: Optimizado para documento PDF

### 5. Organización

```
images/
├── panel_recepcion.png
├── panel_veterinario.png
├── ver_cita.png
├── panel_usuario.png
└── responsive_design.png
```

Las imágenes estarán listas para ser incluidas en el documento del TFG.
